# Projeto: Landing Page Marcograf Indústria Gráfica

## 1. Contexto geral do projeto

Este projeto consiste no desenvolvimento de uma landing page moderna, responsiva, otimizada e comercial para a empresa **Marcograf Indústria Gráfica**, uma gráfica localizada em Fortaleza/CE, com atuação consolidada há 25 anos no mercado.

A Marcograf possui uma imagem de tradição, qualidade técnica e confiabilidade, com serviços gráficos em diferentes segmentos, incluindo editorial, rótulos e embalagens, publicidade, papelaria e comunicação visual.

A nova landing page deve reposicionar digitalmente a empresa, substituindo uma comunicação mais antiga/institucional por uma apresentação moderna, objetiva, visualmente forte e focada em conversão.

O objetivo é que qualquer visitante entenda rapidamente:

- O que a Marcograf faz;
- Por que a empresa é confiável;
- Quais serviços oferece;
- Como solicitar um orçamento;
- Onde a empresa está localizada;
- Como entrar em contato.

A página deve ter aparência profissional, limpa, moderna e alinhada à identidade visual da marca.

---

## 2. Objetivo principal da landing page

O objetivo principal da landing page é converter visitantes em contatos comerciais qualificados.

A página deve incentivar o usuário a:

- Solicitar orçamento;
- Entrar em contato por telefone;
- Enviar e-mail para orçamento;
- Conhecer os serviços oferecidos;
- Ver a localização da empresa;
- Entender os diferenciais da Marcograf;
- Confiar na empresa por meio de dados institucionais, tempo de mercado e avaliações.

## 7. Identidade visual

### Logo

A logo da Marcograf possui tipografia preta, forte e institucional, com símbolo colorido que remete às cores de impressão.

O símbolo possui cores associadas ao universo gráfico, especialmente ao padrão CMYK:

- Ciano;
- Magenta;
- Amarelo;

A landing page deve usar uma estética inspirada em impressão gráfica, mas sem ficar carregada.

A proposta visual deve combinar:

- Fundo claro;
- Tipografia forte;
- Elementos pretos e grafite;
- Detalhes em CMYK;
- Cards limpos;
- Seções com bastante espaçamento;
- Ícones simples;
- Linhas decorativas;

9. Tecnologias recomendadas

Utilizar uma stack moderna, comum no mercado e adequada para landing pages performáticas.

Stack principal
React
TypeScript
Vite
Tailwind CSS
Bibliotecas recomendadas
Lucide React para ícones;
Framer Motion para animações leves;
React Hook Form para formulário;
Zod para validação;
@hookform/resolvers para integração entre React Hook Form e Zod;
React Helmet Async para SEO;
clsx para classes condicionais;
tailwind-merge para merge seguro de classes Tailwind.
Deploy sugerido
Vercel;
Netlify;
Cloudflare Pages.
Justificativa da stack

React com TypeScript e Vite é uma combinação moderna, rápida e comum para desenvolvimento frontend.

Tailwind CSS facilita a criação de uma interface responsiva, consistente e visualmente limpa.

React Hook Form com Zod permite construir formulários mais seguros, validados e fáceis de manter.

Framer Motion deve ser usado com moderação, apenas para animações suaves.

React Helmet Async ajuda a configurar metadados importantes para SEO.

import { z } from "zod";

export const contactFormSchema = z.object({
  name: z.string().min(2, "Informe seu nome."),
  company: z.string().optional(),
  email: z.string().email("Informe um e-mail válido."),
  phone: z.string().min(8, "Informe um telefone válido."),
  serviceType: z.string().min(1, "Selecione o tipo de serviço."),
  quantity: z.string().optional(),
  deadline: z.string().optional(),
  message: z.string().min(10, "Descreva brevemente sua solicitação.")
});

export type ContactFormData = z.infer<typeof contactFormSchema>;
36. Comportamento do formulário sem backend

Na primeira versão, se não houver backend, o formulário deve gerar um link mailto.

Exemplo de função
import type { ContactFormData } from "./contactFormSchema";

export function buildMailtoLink(data: ContactFormData) {
  const subject = encodeURIComponent("Solicitação de orçamento pelo site");

  const body = encodeURIComponent(`
Olá, gostaria de solicitar um orçamento com a Marcograf.

Nome: ${data.name}
Empresa: ${data.company || "Não informado"}
E-mail: ${data.email}
Telefone: ${data.phone}
Serviço: ${data.serviceType}
Quantidade estimada: ${data.quantity || "Não informado"}
Prazo desejado: ${data.deadline || "Não informado"}

Mensagem:
${data.message}
  `);

  return `mailto:orcamento@marcograf.com.br?subject=${subject}&body=${body}`;
}
